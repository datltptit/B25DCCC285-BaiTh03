
# ShopMini Ứng dụng cửa hàng mini bằng React + TypeScript (Vite). State toàn cục quản lý bằng Context API và Redux Toolkit. ## Chạy project ```bash npm install npm run dev # chạy dev tại http://localhost:5173 npm run build # kiểm tra TypeScript + build ``` ## Chức năng - Trang: `/`, `/products/:id`, `/cart`, `/login`, `/checkout`, 404 - Trang chủ: lưới responsive (1/2/4 cột), tìm kiếm theo tên - Header dùng chung: số lượng sản phẩm trong giỏ, tên người dùng, đăng xuất, đổi theme sáng/tối - Context API: `ThemeContext` (`useTheme`), `AuthContext` (`useAuth`, đăng nhập giả lập với password `123456`) - Redux Toolkit: `productsSlice` (createAsyncThunk, loading/succeeded/failed), `cartSlice` (addToCart, removeFromCart, updateQuantity, clearCart + selector tổng số lượng, tổng tiền) - `/checkout` là protected route: chưa đăng nhập thì chuyển sang `/login`, đăng nhập xong quay lại trang trước - Nút "Đặt hàng" xoá giỏ và hiện thông báo thành công - TypeScript đầy đủ, không dùng `any` API: https://fakestoreapi.com/products # B25DCCC285-BaiTh03
